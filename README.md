# QuietZone

QuietZone is a disaster-response prototype designed to identify potentially vulnerable areas where reliable ground-level information is missing.

## Problem

During disasters, network disruptions and limited reporting can leave affected communities unaccounted for. A lack of incoming reports does not necessarily mean an area is safe.

## Approach

QuietZone prioritizes areas for field verification using hazard severity, population exposure, connectivity disruption, and time since the last verification.

## Technology Stack

- React
- Vite
- Tailwind CSS
- Leaflet and OpenStreetMap
- Browser LocalStorage
